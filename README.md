# Anky — Frontend for Pteros Business Management API

Anky is a modern, versatile dashboard and management interface for the [Pteros Business Management API](https://github.com/Diogo-Falardo/Pteros-Business-Management-API-Multi-Tool).  
It provides a seamless user experience for managing business entities, users, inventory, and more.

## Current features:

- **Staff Mangement** : Able to create roles, update its permissions and change the roles of staff members

## How to run the project

```
bun install
bun run dev
```
